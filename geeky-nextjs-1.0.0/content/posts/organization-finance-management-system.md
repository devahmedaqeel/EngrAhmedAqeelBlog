**Organization Finance Management System** is an enterprise-grade financial management platform developed as a Final Year Project to handle organizational income, expenses, analytics dashboards, and auditing reports.

### Tech Stack & Technologies

- **Frontend:** React.js, Bootstrap
- **Backend:** Node.js, Express.js REST API
- **Database:** MongoDB
- **Security:** JWT Authentication & Role-Based Access Control

### Key Features

- **Income & Expense Tracking:** Categorizes financial transactions with itemized logging and budget allocation.
- **Analytics & Reporting:** Generates visual financial charts, revenue vs. expense comparisons, and exportable PDF audit reports.
- **Role-Based Access Control:** Secure user permission levels for accountants, managers, and administrative executives.
