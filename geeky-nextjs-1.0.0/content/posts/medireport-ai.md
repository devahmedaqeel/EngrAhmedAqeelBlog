**MediReport AI** is an AI-powered medical lab-report analyzer that extracts key physiological and biological metrics from scanned lab reports using OCR pipelines and translates them into plain-language clinical explanations using Large Language Models (LLMs).

### Tech Stack & Technologies

- **Frontend & Mobile:** React Native
- **Backend Services:** FastAPI (Python)
- **AI & OCR Pipelines:** Google Gemini API, PaddleOCR
- **Cloud & Auth:** Firebase Authentication & Cloud Storage

### Key Features

- **Automated Document OCR:** Scans complex medical lab report documents and extracts tabular diagnostic metrics with high precision.
- **LLM Diagnostic Summaries:** Leverages Google Gemini to interpret medical terminology and output easy-to-understand health summaries for patients.
- **Secure Authentication & Storage:** Built-in user authentication with cloud synchronization for historical lab report tracking.
