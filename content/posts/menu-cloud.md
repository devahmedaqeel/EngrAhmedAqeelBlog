**MenuCloud** is a comprehensive cloud restaurant-menu platform enabling touchless QR-code ordering, real-time menu management, and an administration analytics dashboard for restaurant owners.

### Tech Stack & Technologies

- **Frontend:** React.js, HTML5, CSS3, Tailwind CSS
- **Backend:** Node.js, Express.js REST API
- **Database:** MongoDB

### Key Features

- **QR-Code Mobile Ordering:** Dine-in customers can instantly scan QR codes on tables to browse interactive digital menus and place orders.
- **Admin Dashboard:** Restaurant managers can update prices, mark items in/out of stock, and track order metrics in real time.
- **Responsive Architecture:** Blazing fast user experience optimized across mobile, tablet, and desktop viewports.
