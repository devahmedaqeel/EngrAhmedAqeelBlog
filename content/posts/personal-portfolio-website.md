**Personal Developer Portfolio Website** is an interactive, high-performance portfolio presenting Engr. Ahmed Aqeel's technical expertise, AI projects, software engineering background, achievements, and contact channels.

### Tech Stack & Technologies

- **Frontend Framework:** Next.js, React.js
- **Styling:** Tailwind CSS, PostCSS
- **Deployment:** Vercel

### Key Features

- **Project Showcase:** Highlights AI, full-stack, and mobile applications with interactive filtering and categories.
- **Resume Integration:** Displays formal education, technical skills matrix, soft skills, and professional experience.
- **SEO Optimized:** Fast server-side rendering, meta tags, and structured schema markup.
