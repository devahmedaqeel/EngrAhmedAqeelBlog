**GiftyGo** is an AI recommendation platform that generates tailored gift suggestions based on recipient personality traits, occasion, budget, and intelligent ranking models.

### Tech Stack & Technologies

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js API
- **AI Integration:** Google Gemini API
- **Database:** MongoDB

### Key Features

- **Personalized Recommendations:** Uses Gemini LLM to interpret recipient preferences and suggest thoughtful, creative gift items.
- **Budget & Occasion Filter:** Dynamically ranks gift ideas according to user price limits and occasion categories (birthdays, anniversaries, holidays).
- **Interactive Discovery UI:** Clean, modern user interface for quick product discovery and save-for-later wishlists.
